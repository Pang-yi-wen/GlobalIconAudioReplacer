全局图标替换工具 · 使用说明
================================================

一、它做什么
------------------------------------------------
把电脑上「所有文件类型」的图标，统一换成你指定的一个 .ico 图标。
包括：各种扩展名的文件、文件夹、磁盘驱动器。

原理：Windows 里文件的图标并不保存在文件中，而是由注册表里的
「文件类型关联」决定。本程序在当前用户的注册表
HKCU\Software\Classes 下，为每一种类型写入 DefaultIcon 指向你的图标。
用户级注册优先于系统级，所以：
  · 不需要管理员权限
  · 不改动系统原有配置（HKLM 一个字都没碰）
  · 不改动、不读取、不移动你的任何文件（快捷方式 .lnk 除外，见第五节）
  · 随时可完整还原


二、怎么用（三种方式，任选）
------------------------------------------------
方式 A：双击 IconReplacer.exe
    出现菜单：
      1 应用图标 → 输入 .ico 路径（也可以把图标文件直接拖进黑窗口）
      2 还原为系统原始图标
      3 查看当前状态
      4 列出将被修改的类型
      0 退出

方式 B：把 .ico 文件拖到 IconReplacer.exe 的图标上
    松手即应用，最省事。

方式 C：命令行（cmd 或 PowerShell 里）
    IconReplacer.exe apply D:\my.ico         应用
    IconReplacer.exe restore                 还原
    IconReplacer.exe status                  查看状态
    IconReplacer.exe list                    列出将被改的类型
    IconReplacer.exe lnktest <ico>           自检快捷方式能否改写（改完立即还原）
    IconReplacer.exe help                    帮助

    可选开关：
      --dry-run        只统计不写入，先看看会改多少项
      --no-folders     只改文件，不改文件夹和驱动器
      --no-refresh     不刷新图标缓存（手动重启资源管理器后才生效）
      --no-restart     刷新缓存但不重启资源管理器
      --install        把图标复制到本机固定目录后再引用（换电脑/移动文件夹也不失效）
      --index N        用 .ico 里的第 N 个图像，默认 0
      --exclude .lnk   排除某个扩展名，可写多个
      --yes            跳过确认，直接执行

    快捷方式与缩略图：
      --no-lnk             不改写快捷方式（.lnk）文件
      --lnk-dir <目录>      额外扫描该目录下的快捷方式，可重复写
      --keep-thumbnails    不关闭缩略图（图片仍按自身内容显示）


三、图标从哪来
------------------------------------------------
只接受 .ico 格式（你选的「现成 .ico」方案）。
如果手上只有 PNG/JPG，可以用在线转换站或 Photoshop/GIMP 存成 .ico，
建议生成时包含 16/32/48/256 多种尺寸，这样各种视图下都清晰。
随包附带的 OIP-C_256x256.ico 是一个示例，可直接拿来试。
这个自带的图标示例为蒋结实。


四、换图标 / 恢复
------------------------------------------------
换：再运行一次 apply 指向新图标即可（会自动先还原旧的）。
恢复：三种都行，效果完全一样——
      1. 双击「一键恢复.bat」（最省事）
      2. 双击 IconReplacer.exe 后菜单选 2
      3. 命令行 IconReplacer.exe restore
      之后会重启资源管理器，图标立刻回到系统原始状态。

restore 一次会还原三样东西：
      · 注册表里写入的 DefaultIcon（约一千个类型）
      · 被改写过的快捷方式图标（逐个写回原值）
      · 被关掉的缩略图设置（恢复成你原来的样子）

万一还原记录丢了怎么办：
      每次 apply 都会在程序目录的 _restore\ 里另存一份还原记录，
      如果 %LOCALAPPDATA% 下那份被清理工具删了，restore 会自动从这儿取回。
      所以：别删 _restore\ 文件夹。


五、三类「硬骨头」现在怎么处理
------------------------------------------------
.lnk
    图标写在每个快捷方式文件的内部，注册表的 DefaultIcon 管不到它。
    所以现在会逐个改写快捷方式文件里的图标位置（IShellLink），
    默认扫描这些地方：桌面 / 公共桌面 / 开始菜单 / 快速启动 / 任务栏固定。
    每个快捷方式原来的图标位置都会记下来，restore 时逐个写回。
      不想动快捷方式：加 --no-lnk
      还要扫别的目录：--lnk-dir <目录>（可重复写）
      想先验证能不能改：IconReplacer.exe lnktest OIP-C_256x256.ico
      （自检会「改一次再还原」，改完立刻恢复原样，不动注册表）
      某个快捷方式怎么都换不掉：
          IconReplacer.exe lnkstrip "C:\完整\路径\某某.lnk"
          它会把文件里那份环境变量图标记录摘掉并报告结构是否完好，
          摘掉之后再重新 apply 一次即可。只动这一个文件，不碰注册表。
    只读的文件会先清掉只读属性再写，写完恢复；实在写不进的，
    运行结束时会连路径带原因一起列出来，不再只报一个数字。

系统图标（此电脑 / 回收站 / 用户文件夹 / 网络 / 控制面板 / 库）
    它们不是快捷方式，也不走文件类型关联，以前根本管不到。
    现在单独写 HKCU 下的 Explorer\CLSID\{GUID}\DefaultIcon，
    同样只动当前用户，restore 一并还原。

.ico
    系统会用缩略图处理器按图片自身内容显示，把图标整个盖掉。
    所以现在除了写 DefaultIcon，还会顺手关掉资源管理器的缩略图
    （等同于勾选「始终显示图标，从不显示缩略图」）。
    代价是图片和视频不再预览。想保留预览：加 --keep-thumbnails

.exe
    已写入 exefile 的 DefaultIcon，尽力而为。
    shell 在部分视图下仍会直接从 exe 资源里提取原图标，这是系统行为，
    注册表层面到此为止，改不了。

其它
    任务栏 / 开始菜单 / 桌面快捷方式属于 .lnk，现在也会被改写
    改完后需要重启资源管理器才会立刻生效，程序默认会自动做这一步
    （会关闭你已打开的所有文件夹窗口，不影响文件）


六、装在别的电脑上
------------------------------------------------
整个文件夹拷到 U 盘或目标电脑桌面即可，IconReplacer.exe 是静态编译的
单文件，不依赖任何运行环境，64 位 Windows 7 及以上都能跑。
注意：图标文件用的是你给的路径，所以图标也要一起拷过去；
      想彻底避免路径失效，加 --install 参数。

每台电脑的还原记录各自保存在
  C:\Users\<用户名>\AppData\Local\GlobalIconReplacer\applied.txt       注册表改动
  C:\Users\<用户名>\AppData\Local\GlobalIconReplacer\applied_lnk.txt    快捷方式原图标
  C:\Users\<用户名>\AppData\Local\GlobalIconReplacer\applied_thumb.txt  缩略图原设置
删掉这些文件不代表不能还原，但会失去精确还原的能力。

中文路径：完全支持。程序全程用 Unicode（宽字符）读写注册表和文件，
控制台的输入输出也不经过 cmd 的代码页，所以中文用户名、中文文件夹名、
中文图标文件名都不会出问题。


七、想改源码自己编译
------------------------------------------------
源码：icon_replacer.cpp（单文件，无第三方库）
用 Dev-C++ 自带的编译器命令行编译：

  "C:\Program Files (x86)\Embarcadero\Dev-Cpp\TDM-GCC-64\bin\g++.exe" ^
    -O2 -std=c++17 -s -static -static-libgcc -static-libstdc++ ^
    -o IconReplacer.exe icon_replacer.cpp -ladvapi32 -lshell32 -lole32

（^ 是 cmd 里的换行符；用 PowerShell 的话换成 ` 反引号）
也可以在 Dev-C++ 里新建工程、把 .cpp 加进去直接编译。


八、卸载
------------------------------------------------
先运行一次 restore 还原图标，然后把这个文件夹整个删掉即可。
无残留：注册表里只有 HKCU\Software\Classes 下本程序写入的
DefaultIcon 项，加上 Explorer\Advanced 下的缩略图开关，
restore 会全部清除或恢复原值。
